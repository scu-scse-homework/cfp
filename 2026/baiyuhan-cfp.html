# International Workshop on AI-Driven Cyber Security and Privacy (AICSP 2026) ## Overview The International Workshop on AI-Driven Cyber Security and Privacy (AICSP 2026) aims to provide a platform for researchers, students, and industry practitioners to discuss emerging challenges and innovative solutions in the field of cyber security and privacy protection. With the rapid development of artificial intelligence, cloud computing, blockchain, and large-scale network systems, cyber threats have become increasingly intelligent and complex. This workshop focuses on cutting-edge research topics related to network security, intelligent defense systems, privacy-preserving technologies, and secure computing. AICSP 2026 welcomes original research papers, system demonstrations, and preliminary research ideas from academia and industry. --- # Topics of Interest Topics of interest include, but are not limited to: ## Network and System Security - Network intrusion detection and prevention - Malware analysis and detection - Distributed system security - Cloud and edge computing security - Zero trust architecture - Software and operating system security ## Artificial Intelligence Security - Adversarial machine learning - Security of large language models (LLMs) - AI-generated attack and defense techniques - Deepfake detection - Federated learning security - Explainable AI for cyber security ## Cryptography and Privacy - Blockchain and smart contract security - Privacy-preserving computation - Secure multi-party computation - Post-quantum cryptography - Data encryption and authentication - Differential privacy ## Emerging Security Applications - Internet of Things (IoT) security - Industrial control system security - Autonomous vehicle security - Mobile application security - Digital forensics - Security risk assessment --- # Submission Guidelines ## Paper Format - Papers must be written in English. - Submissions should follow the standard IEEE conference format. - Full papers: up to 6 pages (excluding references). - Short papers/posters: up to 3 pages. - Templates are available from the IEEE conference template website. ## Review Policy AICSP 2026 adopts a **double-blind peer review** process. Authors should ensure that: - Author names and affiliations are removed from the manuscript. - Self-references do not reveal author identity. - Submitted work is original and unpublished. Each paper will be reviewed by at least two reviewers based on: - Originality - Technical quality - Relevance to workshop topics - Clarity of presentation - Potential impact --- # Important Dates | Event | Date | | -------------------------- | ------------ | | Paper Submission Deadline | May 18, 2026 | | Notification of Acceptance | May 25, 2026 | | Camera-ready Deadline | May 30, 2026 | | Workshop Date | June 5, 2026 | --- # Organization Committee ## Workshop Organizers - 张XX, Sichuan University - 李XX, Sichuan University - 王XX, Sichuan University ## Technical Program Committee The technical program committee consists of researchers and graduate students from the fields of cyber security, artificial intelligence, and network systems. --- # Publication Accepted papers will be included in the workshop proceedings and presented during the workshop sessions.
